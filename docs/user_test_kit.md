# Real-user test kit (15 minutes)

Goal: one real person (loan officer, clinic front-desk/billing staff, or a patient) tries the app.
You need **a quote** and **a before/after time** for the report's Impact section.

Live app: https://cabaka-credit.onrender.com (open it 2 minutes early so the free server wakes up).

## 1. Before (3 min): how it works today
Ask, and write down the answers word for word:
1. "When a patient can't pay a bill / a family applies for a small mortgage, what do you do today, step by step?"
2. "How long does that take you for one person?" → **TODAY'S TIME: ____ minutes/hours**
3. "What's the most frustrating part?"
4. (Patient) "Were you ever offered a 0% medical credit card? Did you know about deferred interest?"

## 2. Try it (7 min): they drive, you stay quiet
- Ask them to pick **Maria Alvarez** (or **Tina Ruiz** for a loan officer) and click **Run Cabaka agents**.
- Start a stopwatch. Stop it when they've read the recommendation and letter and decided approve or send back.
  → **TIME WITH CABAKA: ____ minutes**
- Note where they hesitate, what they click first, and any confusion.
- Optional: ask them to type something unusual in the notes box and run again.

## 3. After (5 min)
1. "Would this recommendation help the borrower? Would you trust it?" (1–5) → ____
2. "Is anything wrong or missing in the numbers or the letter?"
3. "Would you use this? What would have to change first?"
4. "Can I quote you in my class report, by first name and role only?" → yes / no
   **QUOTE:** "______________________________________________"

## 4. Evidence to save
- A photo or screenshot of them using it (no faces needed; their hands on the laptop is fine).
- Their run ID (shown next to the Run button) so the report can point to the exact run.
- Fill in: role ____, today's time ____, time with Cabaka ____, rating ____, quote ____.

Send these to Claude and it will add them to report section 7 and the Impact slide.
